# 天津高考英语 · 备考资料

2020–2026 天津卷 14 次考试整理出来的词表、阅读专项和写作用句。

网页版：https://hy2955.github.io/tianjin-english-2027/

## 内容

| 文件 | 页数 | 说明 |

| `pdf/tianjin-1000-words.pdf` | 25 | 1000 个高频词，含 16 个不规则动词变形 |
| `pdf/tianjin-reading-synonyms.pdf` | 7 | 31 组熟词生义 + 86 对同义替换 |

HTML 版在 `html/`，1000 词的 CSV 在 `csv/`。

## 怎么用

- **1000 词**：每天 34 个，30 天一轮；只要求看到认识，不要求拼写。
- **熟词生义**：背搭配，不背单词（sound + financial/advice/reason = 合理的）。
- **同义替换**：遮住右边，自己把原文改写成选项。
- **写作句**：每天 10 句，六天一轮；第二天先回滚错的。
